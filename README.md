# Каталог услуг

Небольшое одностраничное приложение для ведения списка услуг и их цен. Можно добавлять услуги, редактировать и удалять записи, а также фильтровать список по названию. Состояние приложения управляется с помощью Redux.

## Запуск

Требуется Node.js и Yarn.

```bash
yarn install
yarn dev
```

Откройте адрес, который Vite покажет в терминале (обычно `http://localhost:5173`).

## Команды

- `yarn dev` — запустить приложение в режиме разработки.
- `yarn build` — собрать production-версию в `dist/`.
- `yarn preview` — локально просмотреть production-сборку.
- `yarn lint` — проверить код ESLint.

## Технологии

React, Redux, React Redux, React Router и Vite.
